# Archived Small-Sample RSI Overlay Outputs

This folder contains generated outputs from the earlier 2020-2026 RSI overlay
workflow. They are retained as research history and reference material, but the
active full-history analysis now reads the six 2013-2026 CSV files in
`../full_history_canonical/trades_backtest/` and writes new organized outputs under
`../full_history_research/`.

Archived folders:

- `step1_outputs/` - earlier EDA, RSI prior plots, and follow-up figures.
- `runs/` - earlier RSI sleeve scenario equity files and metrics.
- `prep_outputs/` - stale no-RSI preparation outputs from the Excel-oriented
  prep pass.

The earlier scripts and plan documents remain in `RSI_tests/` because they are
useful references for validation logic and research narrative.
