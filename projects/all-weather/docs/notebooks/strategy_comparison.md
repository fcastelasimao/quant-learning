# Strategy Comparison Notebook

`notebooks/strategy_comparison.py` — marimo notebook for reviewing strategy
comparison and tax analysis bundles. All data is pre-computed; the notebook
never fetches prices or runs backtests.

## Data sources

The notebook reads from up to four artifact bundles:

| Bundle | Generated by | Key files |
|---|---|---|
| Strategy comparison / production validation | `research/production_validation.py` or `research/build_strategy_comparison_report.py` | `manifest.json`, `daily_series.csv`, `monthly_returns.csv`, `summary_metrics.csv`, `calendar_year_metrics.csv`, `rolling_metrics.csv`, `drawdown_events.csv`, `stress_period_metrics.csv`, `risk_contribution.csv`, `turnover_costs.csv`, `leverage_signal_events.csv`, `price_provenance.json` |
| Tax addendum (inside the strategy bundle) | `research/production_validation.py` (D.17) | `rebalance_events.csv`, `tax_summary.csv`, `tax_monthly_series.csv`, `tax_regime_comparison.csv`, `tax_addendum_manifest.json` |
| Full-grid leverage validation | `research/validate_mixed_leverage_oos.py` | `manifest.json`, `structural_full_grid_leaderboard.csv` |
| Rebalance thresholds | `research/rebalance_thresholds.py` | `run_config.json`, `threshold_summary.csv`, `threshold_values.csv` |
| Tax threshold sweep | `research/tax_threshold_sweep.py` (D.18) | `run_config.json`, `threshold_sweep_summary.csv`, `verdict.json` |

## Cells and panels

### Bundle selection

Path selectors for each bundle root. Auto-detects the most recent bundle in
each `results/` subdirectory.

### Growth of Money (E.21)

Two-panel chart (full history + ALLW overlap). Controls:

- **Strategy multiselect** — show/hide individual series
- **Y-axis scale** — log or linear for each panel
- **Leverage markers** — SPY/GLD entry/exit scatter points
- **Rebalance markers** — vertical lines at each rebalance date, alpha scaled
  by trade notional (from `rebalance_events.csv`)

Artifact: `daily_series.csv` (indexed value + overlap indexed value per
strategy per day).

### Drawdowns

Underwater drawdown curve for all strategies. Artifact: `daily_series.csv`
(drawdown column) + `drawdown_events.csv` table.

### Calendar-Year Profile

Multi-panel bar chart: annual return, max drawdown, DD duration, Calmar.
Artifact: `calendar_year_metrics.csv`.

### Rolling Behaviour

2x2 grid: rolling CAGR, max DD, correlation to SPY, beta to SPY (1Y and 3Y
windows). Artifact: `rolling_metrics.csv`.

### Monthly Returns

Per-strategy heatmap (year x month) and histogram. Artifact:
`monthly_returns.csv`.

### Risk Diagnostics

3x4 bar grid of institutional metrics (CAGR, vol, Sharpe, Sortino, Calmar,
Ulcer, MDD, DD duration, VaR, CVaR, downside beta, up capture) on the ALLW
overlap window. Artifact: `summary_metrics.csv`.

### Implementation Realism

Risk contribution bar chart + cumulative transaction-cost drag line. Artifacts:
`risk_contribution.csv`, `turnover_costs.csv`, `stress_period_metrics.csv`.

### Leverage Candidates

Full-grid leaderboard top row, full-history and ALLW-overlap summary metrics,
RSI overlay specs. Artifact: `structural_full_grid_leaderboard.csv` from the
mixed leverage bundle.

### Rebalancing Policy

Pre-tax threshold policy comparison (from the standalone rebalance thresholds
bundle). Growth chart PNG, summary table, ALLW overlap chart. Artifact:
`threshold_summary.csv`, `threshold_values.csv`.

### Tax Cost Analysis (E.22)

Annual stacked bars (capital gains tax, dividend tax, §1256 MTM tax) +
cumulative tax-paid line. Artifacts: `tax_summary.csv`,
`tax_monthly_series.csv`.

### Regime Comparison (E.23)

Side-by-side growth of the same strategy under US-taxable vs ISA (zero tax).
Annotated with total tax drag percentage. Artifact:
`tax_regime_comparison.csv`.

### Tax Threshold Sweep (E.24)

Calmar heatmap: drift policies on the y-axis, OOS windows on the x-axis,
faceted by lot selector. Shows both US and zero-tax regimes when available.
Verdict summary from kill criterion. Artifact:
`threshold_sweep_summary.csv`, `verdict.json`.

## Regenerating bundles

```bash
# Full production validation bundle (includes tax addendum)
conda run -n allweather python -m research.production_validation

# Tax threshold sweep
conda run -n allweather python -m research.tax_threshold_sweep

# Rebalance thresholds (pre-tax)
conda run -n allweather python -m research.rebalance_thresholds
```
